# 裁判文书论证结构标记系统 · 前端原型

对裁判文书的**裁判理由**部分做论证结构的结构化标注与图示。

纯前端，无后端、无构建步骤、无依赖。**双击 `index.html` 即可打开**。

```
index.html  →  选系统（标注 / 教学）  →  登录  →  选团体（班级）  →  工作界面
```

> 数据保存在浏览器 localStorage。顶栏右侧的「重置」图标可恢复初始数据。

需求见 `../需求/需求文档-V0.1.1.md`；标注规范依《中文裁判文书说理部分法律论证结构标注与图示指南 v1.1》。

---

## 两个系统

| | 标注系统 | 教学系统 |
|---|---|---|
| 入口 | `labeling.html` | `teaching.html` |
| 账号 | 工作人员一套 | 师生一套 |
| 组织单位 | **团体**（身份码 + 管理员审核） | **班级**（班级码，输码即入） |
| 团内身份 | 最高管理 / 管理员 / 标注员 / 裁定员 | 老师 / 学生 |
| 侧边栏 | 按身份分区：概览 + 管理区 + 标注区 + 裁定区 | 老师：概览 + 班级管理；学生：概览 + 我的练习 + 我的成绩 |
| 核心链路 | 上传文书 → 建任务细分指派 → 标注 → 裁定定稿 → 导出 | 上传文档 → 标标准答案 → 发练习 → 学生标注 → 相似率统计 |

两套账号、两套外壳、两套浏览器存储，**分开管**；底层引擎共用。

## 标注工作台能做什么

（标注系统与教学系统是同一套）

- **颗粒度对齐**：按句号自动给出切割建议（过渡语词并入其后第一个要素），逐段确认后转为要素
- **要素标注**：在原文中选中文字即创建命题并自动分配序号；先给序号、标签稍后给出
- **关系标注**：按住 Shift 拖动一个图元到另一个图元建立 S / A / M；Ctrl 多选后建 J / I；也可手动输入形式化表达
- **图示**：随标注实时成图，支持拖拽布局、缩放平移、按类型着色（辅助视图，导出不含）
- 序号按原文顺序动态重排，关系引用随之重映射；删除采用「删除 — 重新创建」

## 与需求文档的对应

依《指南 v1.1》执行，两份文档冲突时以 PDF 为准。需求文档 V0.1.1 中已确认的答复按其执行：
序号按原文顺序动态生成、关系靠拖动图元建立、不做撤销栈（删除—重新创建）、
不自动比对差异由裁定者人工比对、导出数据不加密、标签体系任务开始后锁定。

## 原型环境的边界

- **不解析 PDF / Word 二进制**。真实读取 `.txt`；拖入 PDF/Word 时载入内置语料作等价替代，并在界面上标明。
- **Excel 导出为 `.csv`**（带 BOM，Excel 可直接打开），未生成 `.xlsx`。
- PNG/JPG 由 SVG 经 canvas 转换；若浏览器限制，自动回退为 SVG 下载。
- **注册审核**只呈现「等待审核」状态，审核方是开发维护方，系统外。
- **相似率**在前端以简单重合度顶替（命题覆盖 30% + 标签正确 40% + 关系重合 30%），真实算法由后端实现。
- 图示自动布局为自顶向下分层，与指南示例的拓扑、图元、嵌套构造一致，坐标不逐像素还原。
